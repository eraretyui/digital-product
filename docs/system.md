# Устройство и обмен

## Компоненты

| Компонент | Ответственность |
|---|---|
| app.js, workflow-ui.js | Пользовательские сценарии и решения |
| domain.js | Расчёты, баланс, правила и валидация рецептур |
| scene.js | Процедурное 3D-представление |
| agent-workflow.js | Запрос, инструменты, анализ и кандидат изменений |
| llm-provider.js | Локальная модель, схема ответа и разрешённые действия |
| rag.js, vector-bridge.js | Поиск по подготовленной базе знаний |
| import-elma.js | Нормализация файлов и слияние редакций |
| server.mjs, state-validation.js | Локальное хранение, проверки и конфликты версий |
| workflow-api.js, evals.js | Предложения, решения, обратная связь и регрессия |

## Контракт обмена

Текущий структурированный вход - JSON-досье. Нормализованный формат имеет schemaVersion: 1 и массив products. Продукт содержит id, code, title и revisions. Редакция содержит ingredients, processSteps, output, packaging и доступные требования. Точные правила проверяет импортёр.

Также поддерживается исторический формат файлового досье ELMA365 с массивом revisions. Он обрабатывается без прямого доступа к внешней системе. Предпросмотр показывает принимаемые продукты, неполные досье и предупреждения; запись требует подтверждения.

Для 1С, Excel и Word требуется сопоставление полей и преобразование в согласованное досье. Прямые API этих систем и универсальный парсер офисных рецептур в этой версии отсутствуют. DOCX/XLSX поддерживаются как вложения до 10 МБ; DOC не входит в разрешённые типы вложений.

## Целостность

Редакции сохраняются с историей. Кандидат помощника привязан к исходной редакции и её содержимому. При конфликте версии сервер отклоняет устаревшую запись. Целевые критерии не записываются как результаты измерений; принятие изменённого варианта не переносит в него автоматически подтверждение испытаний.

## Публичный комплект

Приложение начинает работу со встроенного набора seeds.js. Личные выгрузки, вложения, состояние и журналы разработки исключены. База знаний описывает правила процесса из docs/business.md; её применимость ограничена этими правилами. В публичную версию перенесены 20 программных регрессионных сценариев.
