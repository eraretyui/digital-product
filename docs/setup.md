# Запуск и проверка

## Основное приложение

Установите Node.js 22 или новее. Скачайте репозиторий и откройте терминал в его папке. Сторонние npm-пакеты для основного интерфейса не требуются.

```bash
npm start
```

Откройте http://127.0.0.1:4173. Сервер доступен только на локальном компьютере. Не открывайте index.html двойным щелчком: сохранение обслуживается сервером.

Первый запуск создаёт data/state.json с тремя демонстрационными продуктами. Новые редакции, документы и история сохраняются в data/. Эта папка исключена из Git. Остановка: Ctrl+C в терминале.

## Необязательный помощник с локальной моделью

Основные расчёты и интерфейс работают без языковой модели. Для интерпретации запросов локальной моделью установите Ollama из официального дистрибутива и подготовьте модели qwen3:1.7b и qwen3-embedding:0.6b. Скачивание моделей выполняет пользователь отдельно; приложение не загружает их автоматически.

Ожидается локальный адрес Ollama http://127.0.0.1:11434. При недоступности модели приложение показывает ограниченный инструментальный режим; поиск может использовать необученные хеш-векторы вместо обученных embeddings. Это различие видно в статусе.

## Необязательный FAISS

Для FAISS нужен совместимый Python с numpy и faiss-cpu. Перечень пакетов находится в requirements-optional.txt. Задайте VECTOR_PYTHON равным пути к нужному интерпретатору. Без этих компонентов работает явно обозначенный поиск cosine на JavaScript.

Пример для PowerShell после самостоятельной подготовки окружения:

```powershell
$env:VECTOR_PYTHON = 'python'
npm start
```

## Проверки

```bash
npm test
```

Основной набор проверяет расчёты, операции, версии, импорт, поведение помощника и серверное сохранение. Настоящий FAISS проверяется при доступном окружении; при его отсутствии тест отмечается пропущенным. Браузерная WebGL-проверка требует отдельно подготовленного Playwright и переменной RUNTIME_NODE_MODULES, иначе пропускается.

Публичный регрессионный набор содержит 20 программных сценариев на демонстрационных данных. Исходный закрытый корпус проектных документов и результаты прежних запусков не публикуются. Этот набор не измеряет точность пищевых моделей на лабораторных данных.

## Хранение и восстановление

Перед резервированием остановите сервер и скопируйте целиком data/, включая вложения. Для восстановления верните согласованную копию этой папки при остановленном сервере. JSON-экспорт библиотеки не заменяет копирование вложений.

Для многопользовательского внедрения нужны аутентификация, права, производственное хранение, резервирование и проверка вложений. Демонстрационные роли интерфейса не являются защитой доступа.
