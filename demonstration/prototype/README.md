# Демонстрация прототипа

Видеофайл: [prototype-demo.mp4](prototype-demo.mp4).

Записаны реальные действия в локальном приложении. Полный кадр интерфейса 1920×1080 сохранён без обрезки, без декоративных рамок и без замены видео статическими слайдами. Переходы и ввод параметров ускорены выборочно; на чтение сравнения, просмотр модели и новой редакции оставлены более длительные паузы. Последовательность действий сохранена. Длительность - 47 секунд. Звуковой дорожки нет.

## Последовательность

1. Открытие продукта из библиотеки.
2. Просмотр состава и вращение 3D-модели.
3. Пересчёт на 250 упаковок по 100 г.
4. Просмотр профиля вкуса и текстуры.
5. Запрос «Снизить сахар на 15%» и сравнение предложения.
6. Принятие предложения и появление редакции 2. Неизвестный выход нового варианта остаётся неизвестным.
7. Просмотр испытаний и формы плана.
8. Разделы документов и утверждения.

Использованы встроенные демонстрационные рецептуры. Помощник работает в показанном инструментальном режиме. Лабораторные результаты и итоговое утверждение не создавались.

Полный процесс с внешней системой готовится отдельно: [Пример полного процесса работы](../full-process/Пример%20полного%20процесса%20работы.md).
