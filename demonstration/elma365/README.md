# Полный процесс на примере ELMA365

Папка для видеозаписи и материалов полного процесса работы.

Сценарий: [Пример полного процесса работы](../full-process/Пример%20полного%20процесса%20работы.md).

Планируемый комплект:

- `full-process.mp4` - непрерывная запись работы с полным кадром интерфейса.
- `scenario.md` - последовательность действий и пояснения к видео.
- `example/` - подготовленные для публикации входные файлы и описание результата.

Полный процесс с ELMA365 пока не записан. До размещения материалов используется ссылка на сценарий, без подмены отсутствующего видео другим роликом.
